Agent memo review

Arriving in a later release

The bounded agent workflow (research-memo runs with typed read tools, tool budgets, persistent checkpoints, and export approval) arrives with the agent wave. This page is the review shell it will use.

When it ships, this panel will list agent runs, their validation results, and per-run approval-gated exports. Memos are generated by the same constrained-writer rules as briefs: filing evidence only, citation-gated statements, numbers rendered by code from fact cards, and no investment advice.

Planned review surface

  • Run list with status (draft, awaiting approval, exported, failed).
  • Memo text with per-statement citation links into the filing viewer.
  • Validation record: schema, citations, numeric checks, advice policy.
  • Approval controls tied to run id + exact memo content hash + expiry.
